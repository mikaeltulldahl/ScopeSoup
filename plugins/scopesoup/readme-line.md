## Open the Scope Soup board

This project's work is run with Scope Soup. Run `scopesoup open` in this repository to open the board in your browser. If `scopesoup` is not found, Scope Soup is not installed on this machine or its `bin` folder is not on the PATH: see [the install steps](https://github.com/mikaeltulldahl/ScopeSoup/blob/main/docs/RUNNING.md#installing-and-upgrading).
